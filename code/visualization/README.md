# Visualization

## 1. Purpose

报告/QC 图表绘制工具。

## 2. What Belongs Here

- 与本目录职责直接相关的文件。
- 能帮助后来的人理解实验、代码或结果的索引说明。
- 必要时放 README、manifest、报告或轻量配置；大型数据和 checkpoint 不放在文档目录。

## 3. Update Rules

集群上使用 headless backend；图表命名要可追溯到 run_id。
