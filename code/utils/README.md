# Utilities

## 1. Purpose

共享工具层：路径、配置、IO、日志、seed。

## 2. What Belongs Here

- 与本目录职责直接相关的文件。
- 能帮助后来的人理解实验、代码或结果的索引说明。
- 必要时放 README、manifest、报告或轻量配置；大型数据和 checkpoint 不放在文档目录。

## 3. Update Rules

不要放实验特定逻辑；工具应稳定、可复用、少副作用。
