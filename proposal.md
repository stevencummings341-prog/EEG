# Proposal

This project studies why motor imagery EEG decoders lose accuracy across sessions and how to design adaptation mechanisms grounded in observed drift. The current evidence suggests that simple statistic-only alignment is not sufficient, so the next diagnostic target is prototype drift in the learned representation space.

The engineering framework now supports multiple datasets through a stable `code/` architecture: WBCIC-SHU provides completed baselines; SHU 2022 will be indexed as a second dataset for repeated protocols and cross-dataset checks.
